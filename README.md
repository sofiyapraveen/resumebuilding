# resumebuilding

A responsive web application that lets users create, preview, and download professional resumes in PDF format.

## ✨ Features
- **Interactive UI** – Built with React + Vite for a fast, modern frontend.
- **Tailwind CSS v4** – Clean, utility-first styling.
- **Dynamic Resume Sections** – Add personal details, experience, skills, education.
- **PDF Export** – Generate a downloadable PDF using `html2pdf.js` / `jspdf`.
- **Responsive Layout** – Works seamlessly on desktop and mobile.

## 🛠️ Tech Stack
- **Frontend:** React 18, React Router DOM
- **Build Tool:** Vite 7
- **Styling:** Tailwind CSS v4
- **Utilities:** Axios, Moment.js, React Icons, Lucide React
